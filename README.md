# Online Payment Fraud Detection – Case Study

This project focuses on detecting fraudulent online payment transactions using data analytics and machine learning techniques.
The goal is to analyze transaction patterns, handle class imbalance, and build models that can accurately identify fraudulent activities.

## Problem Statement
Online payment systems are highly vulnerable to fraud due to the increasing volume of digital transactions.
Fraudulent transactions are rare compared to legitimate ones, making the dataset highly imbalanced and challenging for traditional models.

## Objective
To build a fraud detection model that can effectively distinguish between fraudulent and legitimate transactions while minimizing false positives and false negatives.

## Approach
1. Data understanding
2. Exploring relationship and insights in dataset
3. Undersampling (for class-imbalance), target selecion and feature split
4. Trainig classification model with logidtic regression classifier and its evaluation
5. Training model wiith random forest classifier and its evaluation
